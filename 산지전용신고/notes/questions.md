# 사용자 판단·확인 요청 — 산지전용신고 (1차, 2026.10.13.)

## A. 판단이 필요한 항목

1. **연번 3(기간연장 상한) 본표 유지 여부.** 시행령 제19조제2항 본문은 '합산하여 최초 기간 이내'인데 단서 제4호나목(경영악화·자금부족 등 부득이한 사유)은 상한이 없어 반복 연장 관행이 문언상 배제되지 않습니다. 상한을 두는 개정은 사실상 규제 강화이고 입법사실이 진천군 1인 진술 + 타 지역 전언(지자체 특정 불가)이라 경계 사례로 보았습니다. 본표에 두되 [유의]에 규제영향 검토 필요를 적었습니다. 본표 유지 / 검토메모로 이동 중 선택해 주세요.
2. **연번 2·4의 개정 방향 선택.** '예치 후 수리'로 일원화(법 제16조제1항제3호 축소)할지, '수리 후 예치·효력 유보'로 통일(시행규칙 제15조제5호 삭제)할지 두 안을 병기했습니다. 법제처 제출용으로 한 안을 우선 제시해야 한다면 어느 쪽인지 알려 주세요. 현재 서식·시행령 제15조제3항 단서와의 정합성을 보면 전자(예치 후 수리)가 개정 폭이 작습니다.
3. **검토메모의 '부수 정비 검토 가능' 항목(처리기간 25/10/5일 체계, 별지 제7호의4 기간연장신고서 5일, 시스템 통지 도달 간주, 변경신고 형식 사항 분리)을 본표의 개정 방향에 합칠지** 여부.

## B. 원문 확인 요청(국가법령정보센터)

1. **산지관리법 부칙(법률 제21960호, 2026.9.22.)** — 검색창에 「산지관리법」 입력 → 본문 맨 아래 '부칙' → 제1조(시행일)에서 제15조의2제10항·제2조제2호다목·제15조의2제4항의 시행일(2027.3.23.인지)과 경과조치를 확인해 주세요. 결과는 검토메모 5·6번 행의 서술에만 영향을 주며 본표 결론은 바뀌지 않습니다.
2. **행정절차법 시행규칙 — 처리기간에 산입하지 않는 '선행사무'** — 「행정절차법 시행규칙」 검색 → 본문에서 Ctrl+F "선행사무" 또는 "산입". 복구비 예치 통지~예치까지의 기간이 불산입 대상으로 지정되어 있는지 확인해 주세요. 지정되어 있으면 연번 2의 [문제점] ①을 "불산입 근거는 있으나 산지관리법령에 연결 규정이 없음"으로 완화해 다시 보고하겠습니다. 없으면 "없음"이라고만 알려 주세요.
3. **산지관리법 시행규칙 별표 2(산지전용기간 기준)·별표 1의4(일시사용기간 기준)** — 「산지관리법 시행규칙」 → '별표/서식' 탭. 제목과 기간 구간만 알려 주셔도 됩니다(연번 3 [현행 규정] 보강용).
4. **산지전용통합정보시스템(산이랑)의 처리기간 계산 방식(토·공휴일 산입 여부)과 수리 통지 방식** — 법령으로 확인할 수 없는 사실입니다. 산림청 산지정책과 또는 한국산지보전협회(시스템 위탁운영, 시행령 제3조의5제5항)에 문의하면 됩니다. 답을 받지 못해도 결과물은 "진술에 따르면 주말 산입"으로 검토메모 3번 행에 기록되어 있습니다.

## C. 기초정보 확인

- 선유아(산림청 산지정책과) 주무관의 직급·담당 업무가 녹취록에 없어 '대상' 열에 "직급 확인 필요"로 두었습니다.
- 2026.9.10. 인터뷰 면담자 김현빈의 발언은 녹취록에 없어 인용하지 않았습니다.
