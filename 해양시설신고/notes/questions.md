# 사용자 판단 요청 (2차, 2026.10.12 원문 대조 후)

## A. 해소된 항목 (1차 목록 기준)
1. 연번 11·12(법정 외 서류 요구): 현행 시행규칙 제17조에 공동이용 확인 조항이 없고 별지 제12호서식에도 확인사항란이 없음을 원문으로 확인 → **본표 유지**. 1차 보고 2차 수정분의 '조항 있음' 서술은 오류였음.
2. 연번 6·7(최초신고 기한 부재): 시행규칙 제17조제1항에 기한이 없음을 원문으로 확인 → **본표 유지**. 해수부 FAQ의 '30일'은 법령 근거 없음.
5. 기초정보: 변동 없음.

## B. 판단이 여전히 필요한 항목
3. 연번 8~10(대표자 변경의 수리 불요화·과태료 차등): 포항청 의무 유지 입장을 반영해 '의무 존치 + 절차 간소화 + 금액 차등'으로 한정함. 이 처리에 동의하는지.
4. 연번 7(군산청 신고 시점 모호, 인터뷰이는 입법 불요 의견): 별도 행 유지 또는 연번 6에 합칠지.
6. **(신규)** 법령 대조 중 발견한 부수 정비 사항 3건을 본표에 올리지 않고 검토메모에 둔 처리에 동의하는지: ① 별지 제12호서식 첨부서류란의 '법 제32조' 오기, ② 대표자 변경 시 해수부 변경신고와 해경 변경검인의 중복(시행규칙 제17조제3항·제19조제4항), ③ 폐업신고의 법률 근거·기한 부재(법 제33조에 폐업 문언 없음, 제17조제7항 기한 없음).
7. **(신규)** 연번 3~5의 '개정 필요사항' 셀이 약 4,500자여서 열 너비 250에서도 행 높이 상한(409pt) 안에 다 보이지 않을 수 있음. 셀을 더 줄일지(일반법 설명 삭제), 현재대로 둘지.

## C. 법령 검색으로 확인할 수 없는 사실 (담당 기관 문의 필요)
- 시행규칙 별표 1 제1호 라목이 재위임한 '해양수산부장관이 정하여 고시하는 계류시설, 하역설비' 고시의 제정 여부: 국가법령정보센터 행정규칙 DB 검색 3회에서 확인되지 않음. 해양수산부 해양보전과(해양시설 신고 소관)에 문의. 답을 받지 못해도 결과물은 '고시 확인되지 않음(위임사항 미이행 가능성)'으로 처리되어 있음.
- 법인 등기사항증명서·사업자등록증명이 지방해양수산청의 행정정보 공동이용 대상 정보인지: 행정안전부 행정정보공동이용센터. 현재 결과물은 공동이용 대상을 전제로 작성(대상이 아니면 연번 11·12의 개정 방향 ①을 '신고인 첨부' 방식으로 수정).
